## Target Audience

### Primary: Professional Developers
- Use Postgres daily for work
- Frustrated with existing tools (too heavy, ugly, or expensive)
- Value speed and keyboard shortcuts
- Ages 25-45

### Secondary: Data Engineers / DBAs
- Manage multiple databases
- Need advanced features (migrations, schema diff)
- Care about team collaboration
- Company pays for tools

### Tertiary: Students / Hobbyists
- Learning databases
- Side projects
- Price-sensitive
- Word-of-mouth potential

---

## Key Messages

### Why db-gui?

1. **Fast** - Native performance. Opens instantly. Queries fly.
2. **Beautiful** - Modern UI that respects dark mode.
3. **Focused** - PostgreSQL-first. Not trying to support 50 databases poorly.
4. **Fair pricing** - Generous free tier. No per-seat enterprise sales calls.

### What we're NOT

- Not an "enterprise platform" with 500 features
- Not a web app running in Electron pretending to be native
- Not a tool that requires a PhD to configure
