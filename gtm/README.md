# GTM (Go-to-Market)

This folder contains everything related to db-gui's go-to-market strategy, marketing, and commercial operations.

## Structure

```
/gtm
  /web        → Next.js marketing site (landing page, pricing, etc.)
  /strategy   → Pricing, positioning, and GTM documentation
```

## Quick Reference

- **Product**: db-gui - A modern PostgreSQL desktop client
- **Pricing Model**: Free + Pro + Team tiers
- **Target**: Developers, data engineers, DBAs who work with PostgreSQL

## Key Files

- `strategy/pricing.md` - Tier definitions and feature matrix
- `strategy/positioning.md` - Target audience and messaging
- `web/` - Marketing site source code
