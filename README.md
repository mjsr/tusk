# db-gui

A modern PostgreSQL desktop client built with Electron and React.

## Features (Planned)

- SQL query editor with syntax highlighting
- Schema browser with table/column exploration
- Inline data editing
- Connection manager for multiple databases

## Status

**In Planning** - See [claude/planning/PROJECT_PLAN.md](./claude/planning/PROJECT_PLAN.md) for details.

## Tech Stack

- Electron
- React + TypeScript
- TailwindCSS
- Monaco Editor
- node-postgres
